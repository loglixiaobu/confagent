# ConfAgent：研究问题与后续方案

更新：2026-10-21

## 一、问题为什么重要

工具智能体通过查询、计算、预约等步骤完成任务。**一次编造参数、遗漏前置条件，就可能影响后续执行；调用看似合理，也可能提前结束而没有完成任务。** 全部步骤都复查又会增加计算成本。

因此，我们研究：能否估计每一步的可靠性，把检查资源优先分配给薄弱位置，再把经过验证的纠错经验用于后续任务。价值最终体现在**任务完成率与总开销**，不能只看一个评分指标。

## 二、已有研究做了什么，还需要解决什么

| 方向与代表工作 | 已有基础及与本项目的关系 |
|---|---|
| 自评与一致性：[Just Ask for Calibration](https://aclanthology.org/2023.emnlp-main.330/)、[SelfCheckGPT](https://aclanthology.org/2023.emnlp-main.557/)（2023） | 分别研究自报置信度、多次生成的一致性；主要证据来自问答或文本事实性，不能直接当作工具调用正确概率。 |
| 不确定性驱动执行：[SAGE-Agent](https://aclanthology.org/2026.findings-acl.2028/)、[Proxy Confidence](https://arxiv.org/abs/2610.03894)（2026） | 已研究缺信息时主动澄清，以及候选动作评分、执行门控和置信度反馈，说明“置信度指导行动”已有直接相关工作。后者为预印本。 |
| 反思与记忆：[Reflexion](https://arxiv.org/abs/2303.11366)（2023） | 将执行反馈写成反思记忆，改善后续尝试，为经验复用提供了基础。 |

这些工作不能直接替代本项目中的三项验证：**工具步骤标签是否可信；旧任务上的概率能否推广到新任务；计入评分、检查和重试成本后，纠错与经验复用是否仍有收益。** 这是我们的具体切入点，当前定位为可复现的验证研究，方法创新尚需后续对照支持。

## 三、我们目前完成了什么

使用 Qwen3-8B，在 API-Bank 的模拟工具环境中完成：

- **标签修订**：保留原标签和原因，198 次调用清洗为 **158 正、40 负**，区分调用正确与整个任务完成。
- **信号筛选**：同一批旧步骤上，logprob、自陈、一致性的 AUROC 为 **0.6351 / 0.7172 / 0.8812**；一致性最值得继续验证。
- **概率校准与接口**：调用前额外采样 3 次，将一致性映射成正确概率并给出复查建议。按任务分组的内部评估中，Brier **0.1235 → 0.0917**，数值越低表示概率误差越小。
- **新任务验证**：30 个任务、50 次调用，**49 正 / 1 负，任务交付合格 22/30**；校准 Brier **0.0599**，尚未胜过固定先验 **0.0527**。

**当前完成的是第一阶段最小原型。** 旧数据被反复用于开发；新任务仅有一个调用错误，尚不能证明稳定推广。标签由屏蔽分数的模型代理复核，尚无独立人工双标；实际纠错收益和递归改进均未验证。[实验、图表与代码导读](项目速读.md)

## 四、后期预期结果：思路、实验与验证

总体思路：**先验证评分，再接入一次局部纠错，最后复用有效经验。** 以下均为待检验目标。

| 预期结果 | 最小设计与实验 | 验证方案 |
|---|---|---|
| ① 新任务上能识别风险，概率更可靠 | 固定现有采样与校准规则，在未参与现有实验的新任务上自由执行，分别标注调用和结束结果。 | 按任务隔离开发／测试，测试集不调参；与原始一致性、logprob、固定先验比较。看 AUROC（区分对错）、Brier／ECE（概率误差）及按任务计算的不确定区间。 |
| ② 同样预算下，复查能提高完成率 | 低一致性时核对参数来源、单位和前置条件；每任务最多检查一次、修正一次，缺信息则追问。 | 同一批任务、同一模型和总 token 上限，对比**不检查／随机检查／一致性触发检查**。后两组共用检查器与检查次数上限；比较完成率、修好／误改数量及全部开销。未获回复的追问不算完成。 |
| ③ 经验证的经验能帮助未见任务 | 只将核验有效的通用纠错规则存入可检索记忆，先不做模型训练。 | 固定纠错流程，在未参与经验构建的任务上比较**有／无记忆**。测试答案不写入记忆；相同预算下完成率提高，或完成率不降低时单位成功任务成本下降，才支持经验复用有效。 |

实验前固定任务规模与预算，关键错误标签安排人工抽查，并区分模型错误与模拟环境误判。负例不足、概率未胜简单基线或纠错收益抵不过开销时，应如实报告适用边界，**不预设提升幅度，也不把重复试错算成独立样本**。
