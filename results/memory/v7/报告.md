# ConfAgent 版本化事实记忆与证据边界

此轮使用独立新题。所有组均明确保存事实是有效依据，以及 ToolSearcher 仅检索工具说明。三组使用相同的输入与输出总预算，单次输出上限为 1536 token。

三个比较的单侧预设显著性水平为 0.003125。

使用 Qwen3-8B 评估三个受控分区。A 组没有跨会话事实记忆。B 组根据已知用户和事实槽位选取最新有效记录。更新分区另设 C 组，按时间顺序提供同一槽位的真实历史记录，并交由模型判断当前有效的值。

安全对照中，A 正确 8/8，B 正确 8/8。对照包含撤回、用户不匹配、槽位不匹配和当前轮覆盖历史值。
